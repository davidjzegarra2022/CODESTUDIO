# Code Studio — Web & App Creation

Página web oficial de **Code Studio**: creación de páginas web y aplicaciones corporativas para empresas y negocios.

## Estructura
- `index.html` — página principal
- `css/styles.css` — estilos
- `js/main.js` — interacciones (menú, animaciones, formulario a WhatsApp)
- `img/` — logo

## Configuración
Cambia tu número de WhatsApp en `js/main.js` (línea 2) y en la sección Contacto de `index.html`.

## Publicar
Importa este repositorio en Vercel o activa GitHub Pages (rama `main`, carpeta raíz).
